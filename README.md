An interactive CRM Campaign Dashboard developed in Microsoft Excel for analyzing marketing campaign performance, lead conversion trends, revenue generation, and ROI tracking.

Project Overview

This project demonstrates how Excel can be used to create a professional business intelligence dashboard for CRM analytics. The dashboard provides visual insights into campaign performance using Pivot Tables, Charts, KPI Cards, and Interactive Slicers.

The dashboard helps analyze:

Lead generation
Conversion performance
Campaign ROI
Revenue trends
Regional performance
Sales representative contribution
